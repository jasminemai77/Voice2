# Roadmap

- **v0.1** — Provider contracts, hardware detection, safe scheduler, runtime profiles, API and Fake realtime tests.
- **v0.2** — Validated VoxCPM/CosyVoice adapter, local model manager, Web UI and signed Windows desktop packaging.
- **v0.3** — Persisted per-hardware microbenchmarks, streaming playback, OpenAI compatibility and full degradation ladder.
- **v0.4** — Silero VAD, faster-whisper ASR, session state machine and full-duplex interruption.
- **v0.5** — llama.cpp/remote opt-in LLM Providers, tools, memory and complete cascade conversations.
- **v0.6** — WebRTC/LiveKit Transport and native Speech-to-Speech Providers.

AMD GPU support is not promised in the first release. CPU fallback remains available and must be labelled non-realtime when measurements exceed RTF 1.
